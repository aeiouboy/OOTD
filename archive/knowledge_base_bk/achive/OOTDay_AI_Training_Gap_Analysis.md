## 🆕 CATEGORY 41: Conversational Patterns & Natural Language ⭐⭐⭐

### **WHY THIS IS CRITICAL:**
```
AI needs to understand HOW Thais actually talk!

Current Problem:
✅ We have knowledge (what to recommend)
❌ Missing: HOW to say it naturally in Thai

Example:
Wrong: "I suggest you wear yellow for the King's birthday."
Right: "วันเฉลิมพระชนมพรรษาใส่เหลืองนะคะ! มีเสื้อเหลืองพร้อมยัง? 🟡"
```

### **A. Thai Language Patterns**

```
CASUAL FRIENDLY (คุยเป็นกันเอง):
"ว้าว! สวยมาก! 😍"
"เห้ย! นี่ดีเลย!"
"อยากลองมั้ย?"
"ถูกใจป่าว?"

POLITE HELPFUL (สุภาพช่วยเหลือ):
"ค่ะ/ครับ" at end of sentences
"ขอโทษนะคะ แต่..."
"แนะนำว่า..."
"ลองดูนี่นะคะ"

EMPATHETIC (เข้าใจ):
"เข้าใจเลย!"
"เคยเจอแบบนี้มั้ย?"
"ยากนะ เลือกของ"
"ไม่ต้องเครียดนะ"

EXCITED (ตื่นเต้น):
"เย้! เจอแล้ว! 🎉"
"ปัง! สวยสุดๆ!"
"ต้องลอง!"
"เหมาะมาก!"

CONCERN (เป็นห่วง):
"ระวังนะคะ..."
"อย่าลืมว่า..."
"ต้องเช็คก่อนนะ"
"สำคัญมากเลย!"
```

## 🆕 CATEGORY 42: Error Handling & Edge Cases ⭐⭐⭐

### **WHY THIS IS CRITICAL:**
```
AI will encounter unclear inputs, mistakes, and edge cases!

Need to handle:
❌ Vague requests
❌ Conflicting requirements
❌ Budget too low
❌ Unavailable items
❌ Inappropriate requests
❌ User frustration
```

### **A. Handling Vague Requests**

```
USER: "หาชุดสวยๆ"

❌ BAD:
"ชุดสวยๆ มีเยอะ! เลือกสิ!"
(Unhelpful!)

✅ GOOD:
"อยากได้ชุดสวยๆ นะคะ! 
ช่วยบอกหน่อยได้มั้ย:
- จะใส่ไปไหนอะ? (ทำงาน/เที่ยว/งาน?)
- ชอบสไตล์แบบไหน? (เก๋ๆ/สบายๆ/หรูหรา?)
- งบประมาณเท่าไหร่พอดี?

แล้วจะหาให้เลย! 😊"
```

### **B. Handling Conflicting Requirements**

```
USER: "อยากได้ชุดทำงาน แต่ใส่เที่ยวได้ด้วย งบ 500 บาท แบบ designer"

CONFLICT: Budget too low for designer, work + casual hard to mix

✅ GOOD RESPONSE:
"เข้าใจค่ะว่าอยากได้ชุดใส่ได้หลายโอกาส! 👍

ตามงบ 500 บาท:
- Designer จริงๆ จะยาก (เริ่ม 2,000+ บาท)
- แต่มีแบรนด์ดีๆ ราคาเอื้อมถึงได้นะ!

แนะนำ:
✅ Uniqlo, CPS - คุณภาพดี ราคาโอเค
✅ เลือกชุด smart casual 
   → ใส่ทำงานได้ + เที่ยวชิลๆ ก็โอเค!

ลองดูมั้ย? 😊"
```

### **C. Handling Out of Stock**

```
USER: "ต้องการชุดนี้เลย!"
SYSTEM: Out of stock

✅ GOOD:
"อ๊ะ! ขออภัยค่ะ 😢
ตัวนี้หมดสต็อกพอดี...

แต่มีทางเลือก:
1️⃣ แบบคล้ายๆ กันจากแบรนด์เดียวกัน
2️⃣ รอของเข้ารอบหน้า (ประมาณ 2 สัปดาห์)
3️⃣ ดูแบรนด์อื่นที่สไตล์คล้ายกัน

อยากดูอันไหนคะ? 🤔"
```

### **D. Handling Inappropriate Requests**

```
USER: "หาชุดเซ็กซี่ๆ เปิดเผยๆ หน่อย"

Context: Might be for:
- Party → OK
- Work → Not OK
- Temple → Definitely not OK!

✅ GOOD:
"เข้าใจค่ะ! 
ถามหน่อยนะ - จะใส่ไปไหนคะ?

เพราะแต่ละโอกาสเหมาะกับสไตล์ต่างกัน:
- Party/Club → Sexy glam OK!
- Work → Professional sexy (fitted but covered)
- Casual → Chic comfortable

บอกมาแล้วแนะนำให้นะ! 😊"
```

### **E. Handling User Frustration**

```
USER: "หาไม่เจอเลยอะไรก็ไม่ชอบหมด!"

✅ GOOD:
"เข้าใจเลย! หาชุดที่ถูกใจมันยากจริงๆ 😊

มาลองอีกรอบนะ:
- ลองไปแล้วไม่ชอบตรงไหน?
  (สี? ทรง? ราคา? หรืออะไร?)
- เคยมีชุดที่ชอบมั้ย? แบบไหน?

บอกมาได้เลย จะได้ปรับให้ตรงใจมากขึ้น!
ไม่ต้องเครียดนะ เราช่วยหาให้! 💪"
```

### **F. Handling Budget Constraints**

```
USER: "งบ 200 บาท อยากได้ชุดดีๆ"

Reality: Very limited budget

✅ HONEST + HELPFUL:
"งบ 200 บาทนะคะ! 🤔

ตรงไปตรงมาเลย:
- ชุดใหม่แบรนด์ดีๆ จะยาก
- แต่ยังมีทางเลือกนะ!

แนะนำ:
1️⃣ รอเซล (ลดได้ 50-70%!)
2️⃣ Outlet mall (ของเก่า ราคาดี)
3️⃣ Second-hand คุณภาพดี (เช่น Refash)
4️⃣ เพิ่มงบอีกนิด → โอกาสเยอะขึ้น

ยังสนใจมั้ยคะ? 😊"
```

## 🆕 CATEGORY 45: Outfit Combination Logic ⭐⭐⭐

### **WHY THIS IS CRITICAL:**
```
AI must suggest COMPLETE OUTFITS, not just items!

User says: "หาชุดไปงานแต่ง"
Wrong: "มีเดรสสวยๆ นะ"
Right: "มีชุดเซ็ตให้เลย:
       - เดรสม่วงพาสเทล (฿2,490)
       - รองเท้าส้นสูงนู้ด (฿990)
       - กระเป๋าคลัทช์ทอง (฿790)
       = รวม ฿4,270"
```

### **A. Outfit Building Rules**

```
COMPLETE OUTFIT COMPONENTS:

WOMEN:
1. Top (or dress)
2. Bottom (if not dress)
3. Shoes
4. Bag (optional but recommended)
5. Accessories (optional)
6. Outer layer (if needed)

MEN:
1. Shirt/Top
2. Pants
3. Shoes
4. Belt (if needed)
5. Watch/accessories (optional)
6. Jacket (if needed)

OUTFIT RULES:
✅ Color coordination (refer to color theory!)
✅ Style consistency (all minimalist, all boho, etc.)
✅ Occasion appropriate (all pieces fit occasion)
✅ Weather appropriate (consider climate)
✅ Budget fit (total within budget)
✅ Available sizes (user's size in stock)
```

### **B. Color Matching Logic**

```
SAFE COMBINATIONS:
✅ Neutral + Neutral (black + white)
✅ Neutral + Color (beige + blue)
✅ Monochrome (all shades of blue)
✅ Complementary (use color wheel)
✅ Neutral base + accent color

AVOID:
❌ Too many colors (>3)
❌ Clashing patterns
❌ Same exact color (boring)

EXAMPLE:
User wants: "ชุดไปทำงาน"

GOOD COMBO:
- Navy blazer
- White blouse
- Black pants
- Nude heels
- Brown bag
= 3 colors, all neutral, professional ✅

BAD COMBO:
- Red blazer
- Green blouse
- Yellow pants
- Purple heels
= 4 bright colors, clashing ❌
```

### **C. Occasion-Outfit Mapping**

```
WORK INTERVIEW:
Must: Blazer/Jacket + Formal pants/skirt + Closed-toe heels
Colors: Navy, black, grey, white
Accessories: Minimal, professional
Total: Conservative, polished

WEDDING GUEST:
Must: Dress or formal separates + Heels + Clutch
Colors: Festive (NOT white, not all black)
Accessories: Can be statement
Total: Elegant, celebratory

CASUAL DATE:
Must: Nice top + Jeans/Skirt + Comfortable shoes
Colors: Flattering, feminine
Accessories: Moderate
Total: Effort but not overdone

TEMPLE:
Must: Covered shoulders + Long pants/skirt + Flat shoes
Colors: White or modest neutrals
Accessories: Minimal, humble
Total: Respectful, modest

AI must have these mappings!
```

## 🆕 CATEGORY 47: Multi-Turn Conversation Management ⭐⭐⭐

### **WHY THIS IS CRITICAL:**
```
Fashion advice is rarely one message!

Typical flow:
User: "หาชุดหน่อย"
OOT: "ใส่ไปไหนคะ?"
User: "ทำงาน"
OOT: "งบเท่าไหร่คะ?"
User: "2000"
OOT: [shows options]
User: "อันแรกดีนะ แต่มีสีอื่นมั้ย?"
OOT: [shows color options]
User: "เอาสีนี้ มีไซส์ M มั้ย?"
OOT: [checks stock]

= 6+ turns! AI must maintain context!
```

### **A. Context Retention**

```
AI MUST REMEMBER:

CONVERSATION CONTEXT:
{
  "turn": 6,
  "current_occasion": "work",
  "current_budget": 2000,
  "items_shown": ["item1", "item2", "item3"],
  "user_preferred": "item1",
  "user_asking_about": "item1_color_options",
  "conversation_stage": "refinement"
}

WHEN USER SAYS: "อันแรก"
AI knows: Refers to "item1" from earlier

WHEN USER SAYS: "มีสีอื่นมั้ย?"
AI knows: Referring to current item being discussed

WHEN USER SAYS: "เอาสีนี้"
AI knows: Refers to color just shown

= Maintain conversation thread!
```

### **B. Conversation Stages**

```
STAGE 1: DISCOVERY
Goal: Understand need
Questions: Occasion? Budget? Style?
Output: User requirements clear

STAGE 2: RECOMMENDATION
Goal: Show options
Action: Present 3-5 items
Output: User sees choices

STAGE 3: REFINEMENT
Goal: Narrow down
Questions: Like any? What's wrong?
Output: User preferences clearer

STAGE 4: DECISION
Goal: Help decide
Action: Compare options, answer questions
Output: User ready to buy

STAGE 5: PURCHASE
Goal: Facilitate buy
Action: Check stock, size, provide link
Output: User purchases

AI must recognize current stage!
```
