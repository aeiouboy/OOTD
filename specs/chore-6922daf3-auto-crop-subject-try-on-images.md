## Chore Description

Currently, try-on images generated by the AI may have the subject (model) positioned with significant whitespace/margins around them after background removal. This results in the model appearing small within the frame. To improve the visual quality and ensure the model fills 90%+ of the frame, we need to add an auto-crop post-processing step that:

1. Detects the bounding box of non-transparent pixels (the subject)
2. Crops to that bounding box with 3% padding on all sides
3. Maintains the aspect ratio through appropriate resizing
4. Gracefully falls back to the original image if cropping fails

This will be implemented as a Python script using PIL/Pillow and integrated into the image generation API route after background removal.
