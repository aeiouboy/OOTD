# Occasion Styling Guide / คู่มือแต่งตัวตามโอกาส

## Overview / ภาพรวม

This document provides complete outfit formulas for all 9 core occasions in the OOTDay system. Each occasion includes formality range, key pieces with Thai names, items to avoid, color suggestions, complete look formulas, and budget allocation percentages.

เอกสารนี้ให้สูตรชุดครบเซ็ตสำหรับทุก 9 โอกาสหลักในระบบ OOTDay แต่ละโอกาสรวมถึงช่วงความเป็นทางการ ชิ้นหลัก สิ่งที่ควรหลีกเลี่ยง สีแนะนำ สูตรลุคครบ และสัดส่วนงบ

---

## 1. Work / ทำงาน-ออฟฟิศ

**Formality Range / ช่วงความเป็นทางการ:** 6-9 (Target: 7)

### Key Pieces / ชิ้นหลัก
- เสื้อเชิ้ต (Dress shirt) — Formality 6-7
- เบลเซอร์ (Blazer) — Formality 7-8
- กางเกงสแล็ค (Slacks/tailored pants) — Formality 7
- กระโปรงทรงเอ (A-line skirt) — Formality 7
- เดรสแขนยาว (Long-sleeve dress) — Formality 7-8
- รองเท้าหนังหุ้มส้น (Closed leather shoes) — Formality 7

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- เสื้อแขนกุด (Sleeveless tops) — ดูไม่เป็นทางการ
- กางเกงขาสั้น (Shorts) — ไม่เหมาะกับออฟฟิศ
- รองเท้าแตะ (Flip-flops/sandals) — ไม่เป็นทางการ
- เสื้อยืดธรรมดา (Plain t-shirts) — แคชวลเกิน

### Color Suggestions / สีแนะนำ
สีกรมท่า (Navy), สีขาว (White), สีเทา (Gray), สีดำ (Black), สีเบจ (Beige)

### Complete Look Formula / สูตรลุคครบ
```
Top(7) + Bottom(7) + Blazer(8) + Shoes(7) + Bag(7)
= 5 pieces, Formality range 7-8
```

**Example Look / ตัวอย่างลุค:**
- เสื้อเชิ้ตสีขาว (White dress shirt) — F:7
- กางเกงสแล็คสีกรมท่า (Navy slacks) — F:7
- เบลเซอร์สีกรมท่า (Navy blazer) — F:8
- รองเท้าโลฟเฟอร์หนัง (Leather loafers) — F:7
- กระเป๋าทรงสวย (Structured tote) — F:7

### Budget Split / สัดส่วนงบ
| Item | % of Budget | ฿3,000 | ฿5,000 |
|------|-------------|--------|--------|
| Blazer | 35% | ฿1,050 | ฿1,750 |
| Bottom | 25% | ฿750 | ฿1,250 |
| Top | 20% | ฿600 | ฿1,000 |
| Shoes | 15% | ฿450 | ฿750 |
| Bag | 5% | ฿150 | ฿250 |

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- แอร์ออฟฟิศเย็นมาก (22-24°C) ต้องมีเสื้อคลุมเสมอ
- แต่งตัวเป็นทางการกว่าที่คิดดีกว่าแต่งน้อยไป แสดงความเคารพ
- วันศุกร์อาจแคชวลได้มากกว่า แต่ยังต้องดูดี

## 2. Wedding / งานแต่งงาน

**Formality Range / ช่วงความเป็นทางการ:** 7-10 (Target: 8)

### Key Pieces / ชิ้นหลัก
- ชุดราตรี (Evening gown) — Formality 9
- ชุดไทย (Thai traditional outfit) — Formality 9
- เดรสยาว (Long dress) — Formality 8
- ชุดสูท (Suit) — Formality 8-9
- รองเท้าส้นสูง (Heels) — Formality 8

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- สีขาวล้วน (All white) — สีเจ้าสาว ห้ามเด็ดขาด!
- สีดำล้วน (All black) — เหมือนไปงานศพ
- ชุดสั้นเกินไป (Too short outfits) — ไม่สุภาพ
- กางเกงยีนส์ (Jeans) — แคชวลเกินไป

### Color Suggestions / สีแนะนำ
สีชมพู (Pink), สีฟ้า (Light blue), สีเขียวมิ้นท์ (Mint green), สีทอง (Gold), สีม่วง (Purple), สีอัญมณี (Jewel tones)

### Complete Look Formula / สูตรลุคครบ
```
Dress(8-9) + Shoes(8) + Clutch(8) + Jewelry(8)
= 4 pieces, Formality range 8-9
```

### Budget Split / สัดส่วนงบ
| Item | % of Budget |
|------|-------------|
| Dress | 50% |
| Shoes | 20% |
| Bag/Clutch | 15% |
| Jewelry/Accessories | 15% |

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- เช็คธีมสีจากการ์ดเชิญก่อน บางคู่กำหนดสี
- ผ้าไหมไทยสีสดใสแสดงความเคารพวัฒนธรรม
- งานแต่งเช้าใส่สีอ่อน งานแต่งเย็นใส่สีเข้มได้
- อย่าใส่สีแดงล้วน (บางคู่ไม่ชอบ)

## 3. Party / ปาร์ตี้

**Formality Range / ช่วงความเป็นทางการ:** 5-9 (Target: 7)

### Key Pieces / ชิ้นหลัก
- ชุดเดรสสั้น (Short dress) — Formality 6-7
- จั๊มสูท (Jumpsuit) — Formality 6-7
- ชุดเซ็ต (Matching set) — Formality 6-7
- รองเท้าส้นสูง (Heels) — Formality 7-8
- คลัทช์ (Clutch) — Formality 7

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- ชุดจืดเกินไป (Too plain outfits) — ปาร์ตี้ต้องโดดเด่น
- รองเท้าที่เต้นไม่ได้ (Shoes you can't dance in) — ใส่สบายด้วย
- กระเป๋าใหญ่เทอะทะ (Bulky bags) — ถือคลัทช์ดีกว่า

### Color Suggestions / สีแนะนำ
สีเมทัลลิค (Metallic), สีดำ (Black), สีแดง (Red), sequin, ผ้ามันวาว (Shiny fabrics)

### Complete Look Formula / สูตรลุคครบ
```
Statement top(6) + Bottom(6) + Shoes(7) + Clutch(7)
= 4 pieces, Formality range 6-7
```

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- ปาร์ตี้ในกรุงเทพมักเป็นคลับหรือรูฟท็อป ใส่หรูได้เลย
- ถ้าปาร์ตี้ที่บ้าน ลดความเป็นทางการลงเล็กน้อย
- ปาร์ตี้บริษัท ยังต้องสุภาพ อย่าเปิดเผยมากเกิน

## 4. Date / เดท

**Formality Range / ช่วงความเป็นทางการ:** 4-7 (Target: 6)

### Key Pieces / ชิ้นหลัก
- เดรสสั้น (Short dress) — Formality 5-6
- เสื้อสวยๆ (Nice blouse) — Formality 5-6
- กางเกงขายาวทรงสวย (Tailored pants) — Formality 5-6
- รองเท้าส้น (Low heels/mules) — Formality 5-6

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- ชุดที่ดูไม่ใส่ใจ (Sloppy outfits) — ต้องดูตั้งใจแต่ง
- รองเท้าที่เดินไม่สะดวก (Uncomfortable shoes) — ต้องเดินสบาย
- ชุดที่เปิดเผยเกินไป (Too revealing) — ดูดีแต่สุภาพ

### Color Suggestions / สีแนะนำ
สีแดง (Red), สีชมพู (Pink), สีดำ (Black), สีน้ำเงิน (Blue), ลายดอกไม้ (Floral)

### Complete Look Formula / สูตรลุคครบ
```
Nice top(5) + Tailored bottom(6) + Heeled shoes(6) + Small bag(5)
= 4 pieces, Formality range 5-6
```

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- เดทที่ร้านอาหาร ใส่เดรสสวยๆ หรือเสื้อ+กางเกงดีๆ
- เดทที่คาเฟ่/ห้าง ลดความเป็นทางการลงเล็กน้อย
- ใส่ให้ดูดีแต่ไม่ over ความพอดีคือดีที่สุด

## 5. Cafe / คาเฟ่

**Formality Range / ช่วงความเป็นทางการ:** 2-5 (Target: 4)

### Key Pieces / ชิ้นหลัก
- เดรสลูกไม้ (Lace dress) — Formality 4-5
- เสื้อครอป (Crop top) — Formality 3
- กางเกงยีนส์ (Jeans) — Formality 3-4
- กระโปรงพลีท (Pleated skirt) — Formality 4
- รองเท้าผ้าใบ (Sneakers) — Formality 3

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- ชุดเป็นทางการเกิน (Too formal) — ดูไม่เข้ากับบรรยากาศ
- ชุดกีฬา (Sportswear) — ไม่ถ่ายรูปสวย
- ชุดที่ดูไม่ได้ใส่ใจ (Sloppy outfits) — คาเฟ่ต้องเก๋

### Color Suggestions / สีแนะนำ
สีพาสเทล (Pastel), สีขาวครีม (Cream), สีเบจ (Beige), ลายตาราง (Plaid), ลายดอกไม้ (Floral)

### Complete Look Formula / สูตรลุคครบ
```
Trendy top(3-4) + Bottom(3-4) + Clean shoes(3-4)
= 3 pieces, Formality range 3-4
```

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- คาเฟ่ในกรุงเทพมักถ่ายรูปลง IG ใส่สีพาสเทลถ่ายรูปสวย
- คาเฟ่แอร์เย็น พกเสื้อคลุมบางๆ ไว้
- สไตล์โบโฮหรือมินิมอลเข้ากับคาเฟ่ที่สุด

### Key Pieces / ชิ้นหลัก
- เสื้อยืด (T-shirt) — Formality 3
- กางเกงยีนส์ (Jeans) — Formality 3
- กางเกงขาสั้น (Shorts) — Formality 2
- เดรสแขนสั้น (Short-sleeve dress) — Formality 3
- รองเท้าผ้าใบ (Sneakers) — Formality 3

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- ชุดเป็นทางการเกินไป (Too formal) — วันหยุดต้องสบาย

- ชุดที่ต้องรีด (Wrinkle-prone) — ไม่เหมาะกับวันชิลล์

### Color Suggestions / สีแนะนำ
สีพาสเทล (Pastel), สีขาว (White), สีเดนิม (Denim blue), สีเอิร์ธโทน (Earth tones)


- เลกกิ้ง (Leggings) — Formality 1
- กางเกงขาสั้นวิ่ง (Running shorts) — Formality 1
- เสื้อ Dri-fit — Formality 1

### Color Suggestions / สีแนะนำ
สีดำ (Black), สีเทา (Gray), สีน้ำเงิน (Blue), สีชมพูนีออน (Neon pink), สีเขียวมิ้นท์ (Mint green)

### Complete Look Formula / สูตรลุคครบ

```
Athletic top(1) + Athletic bottom(1) + Sport shoes(1)
```

## 8. Travel / ท่องเที่ยว

**Formality Range / ช่วงความเป็นทางการ:** 2-5 (Target: 4)

### Key Pieces / ชิ้นหลัก
- กางเกงขายาวผ้าบาง (Lightweight pants) — Formality 4
- เสื้อยืดคอตตอน (Cotton tee) — Formality 3
- เดรสแม็กซี่ (Maxi dress) — Formality 4
- รองเท้าเดินสบาย (Comfortable walking shoes) — Formality 3

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- ชุดที่ต้องรีด (Wrinkle-prone) — พับใส่กระเป๋ายับ
- รองเท้าใหม่ (New shoes) — กัดเท้า
- เครื่องประดับราคาแพง (Expensive jewelry) — เสี่ยงหาย

### Color Suggestions / สีแนะนำ
สีกลาง (Neutrals), สีที่ซ่อนรอยเปื้อน (Stain-hiding colors), ลายที่ไม่เห็นรอยยับ (Non-wrinkle patterns)

### Complete Look Formula / สูตรลุคครบ
```
Versatile top(3) + Comfy bottom(4) + Walking shoes(3) + Day bag(3)
= 4 pieces, Formality range 3-4
```

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- เที่ยววัดต้องปกปิด ห้ามเปิดไหล่ ห้ามกางเกงขาสั้น
- เที่ยวทะเลเน้นผ้าบาง แห้งง่าย กันแดด
- เที่ยวภูเขาเหนือ พกเสื้อกันหนาวไว้

## 9. Dinner / ดินเนอร์

**Formality Range / ช่วงความเป็นทางการ:** 5-8 (Target: 7)

### Key Pieces / ชิ้นหลัก
- เดรสค็อกเทล (Cocktail dress) — Formality 7
- เสื้อผ้าไหม (Silk blouse) — Formality 7
- กางเกงผ้าดี (Quality fabric pants) — Formality 6-7
- เบลเซอร์ (Blazer) — Formality 7-8
- รองเท้าหุ้มส้น (Closed-toe shoes) — Formality 6-7

### Avoid Items / สิ่งที่ควรหลีกเลี่ยง
- กางเกงยีนส์ขาด (Ripped jeans) — ไม่เหมาะกับดินเนอร์
- รองเท้าแตะ (Sandals) — ไม่เป็นทางการพอ
- เสื้อยืดธรรมดา (Plain tees) — แคชวลเกินไป
- ชุดกีฬา (Sportswear) — ไม่เข้ากับบรรยากาศร้านอาหาร

### Color Suggestions / สีแนะนำ
สีดำ (Black), สีกรมท่า (Navy), สีเบอร์กันดี (Burgundy), สีเขียวเข้ม (Dark green)

### Complete Look Formula / สูตรลุคครบ
```
Elegant top(7) + Quality bottom(7) + Nice shoes(7) + Small bag(6)
= 4 pieces, Formality range 6-7
```

### Thai-Specific Tips / เคล็ดลับสำหรับคนไทย
- ร้านอาหาร fine dining ต้องใส่ดีหน่อย บางร้านมี dress code
- ร้านอาหารทั่วไป smart casual ก็พอ
- ดินเนอร์โรงแรม 5 ดาว ควร formality 7-8 ขึ้นไป
