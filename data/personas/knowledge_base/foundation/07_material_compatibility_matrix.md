# Material Compatibility Matrix / เมทริกซ์ความเข้ากันของเนื้อผ้า

## Overview / ภาพรวม

This document defines material pairing rules for outfit composition. Fabrics have their own formality levels, and mixing incompatible materials creates visual dissonance. Understanding material compatibility is essential for cohesive outfits.

เอกสารนี้อธิบายกฎการจับคู่เนื้อผ้าสำหรับการจัดชุด ผ้าแต่ละชนิดมีระดับความเป็นทางการของตัวเอง การผสมผ้าที่ไม่เข้ากันทำให้ชุดดูไม่กลมกลืน

## 2. Material Pairing Rules / กฎการจับคู่เนื้อผ้า

### Pairing by Tier Distance / จับคู่ตามระยะห่างของระดับ

| Pairing | Rule | Example |
|---------|------|---------|
| Same tier (A+A, B+B) | ✅ Always safe / ปลอดภัยเสมอ | Silk blouse + Wool pants |
| Adjacent tier (A+B, B+C) | ✅ OK / ใช้ได้ | Poplin shirt + Denim jeans |
| Skip one tier (A+C) | ⚠️ Caution / ระวัง | Chiffon top + Denim (needs careful styling) |
| Skip two tiers (A+D) | ❌ Avoid / หลีกเลี่ยง | Silk blouse + Jersey joggers (never) |

### Specific Pairing Examples / ตัวอย่างการจับคู่เฉพาะ

#### NEVER Pair / ห้ามจับคู่เด็ดขาด ❌
| Combo | Why / เหตุผล |
|-------|-------------|
| Silk + Jersey | ผ้าไหมหรูเกิน ผ้าเจอร์ซี่สบายเกิน ดูขัดกัน |
| Satin + Fleece | ผ้าซาตินทางการ ผ้าฟลีซเป็นชุดอยู่บ้าน |
| Chiffon + Sweatshirt | ผ้าชีฟองบาง ผ้าสเวตเชิ้ตหนา ไม่เข้ากัน |
| Thai silk + Athletic mesh | ผ้าไหมไทยทางการมาก ผ้าตาข่ายกีฬา ห้ามเด็ดขาด |
| Wool suiting + Terry cloth | ผ้าวูลสูทเป็นทางการ ผ้าขนหนูเป็นชุดอยู่บ้าน |

#### OK Pairings / จับคู่ได้ ✅
| Combo | Style Result / ผลลัพธ์ |
|-------|----------------------|
| Fine cotton + Silk | Elegant casual / แคชวลหรู |
| Cotton shirt + Wool pants | Classic office / คลาสสิกทำงาน |
| Denim + Linen | Relaxed smart / สมาร์ตผ่อนคลาย |
| Knit + Chinos | Weekend polished / วันหยุดดูดี |
| Viscose blouse + Denim | Dressed-up casual / แคชวลยกระดับ |

## 3. Thai Climate Material Guide / คู่มือเนื้อผ้าสำหรับอากาศไทย

### Best for Thai Heat / ดีที่สุดสำหรับอากาศร้อน ☀️
| Material | Why | สำหรับ |
|----------|-----|--------|
| Linen | Breathable, quick dry | เสื้อเชิ้ต กางเกง |
| Cotton (thin) | Absorbs sweat, soft | เสื้อยืด เสื้อเชิ้ต |
| Chambray | Light like denim, breathable | เสื้อเชิ้ตแคชวล |
| Viscose/Rayon | Drapes well, light | เดรส เสื้อ |
| Linen blend | Less wrinkly than pure linen | ทุกอย่าง |

### Best for AC Offices / ดีที่สุดสำหรับออฟฟิศแอร์เย็น ❄️
| Material | Why | สำหรับ |
|----------|-----|--------|
| Cotton twill | Warm enough, structured | กางเกง เบลเซอร์ |
| Light wool blend | Temperature regulating | สูท เบลเซอร์ |
| Ponte | Stretchy, warm | กางเกงทำงาน |
| Knit (medium) | Comfortable layering | คาร์ดิแกน สเวตเตอร์ |

### Worst for Thai Weather / ไม่เหมาะกับอากาศไทย 🚫
| Material | Problem | ปัญหา |
|----------|---------|-------|
| Pure wool | Too hot outdoors | ร้อนมากเมื่ออยู่ข้างนอก |
| Polyester (heavy) | Traps heat and sweat | กักความร้อนและเหงื่อ |
| Velvet | Way too hot | ร้อนเกินไปมาก |
| Leather (thick) | Suffocating in humidity | อึดอัดในความชื้น |
| Acrylic knit | Doesn't breathe | ไม่ระบายอากาศ |

## 4. Texture Mixing Rules / กฎการผสมเท็กซ์เจอร์

### Complementary Textures / เท็กซ์เจอร์ที่เสริมกัน ✅
| Texture 1 | Texture 2 | Effect / ผลลัพธ์ |
|-----------|-----------|-----------------|
| Matte มีผิวด้าน | Subtle sheen เงาอ่อน | Adds depth / เพิ่มมิติ |
| Smooth เรียบ | Textured มีลวดลาย | Visual interest / น่าสนใจ |
| Structured ทรง | Drapey พลิ้ว | Balanced contrast / คอนทราสต์สมดุล |
| Knit ถัก | Woven ทอ | Natural pairing / คู่ธรรมชาติ |

### Avoid These Texture Combos / หลีกเลี่ยงเท็กซ์เจอร์เหล่านี้ ❌
| Combo | Why / เหตุผล |
|-------|-------------|
| All shiny ทั้งชุดเงา | Looks costume-like / ดูเหมือนคอสตูม |
| All matte heavy ทั้งชุดด้านหนัก | Looks flat and dull / ดูแบนและทึม |
| Too many textures เท็กซ์เจอร์มากเกิน | Chaotic, no focus / วุ่นวาย ไม่มีจุดเด่น |

### Golden Rule / กฎทอง
Maximum 2-3 different textures per outfit. One should dominate (60%), one supports (30%), one accents (10%).

ไม่เกิน 2-3 เท็กซ์เจอร์ต่อชุด หนึ่งตัวเป็นหลัก (60%) หนึ่งตัวเสริม (30%) หนึ่งตัวเน้น (10%)
