# Style Coherence Framework / กรอบความสอดคล้องของสไตล์

## Overview / ภาพรวม

This document defines 8 core style tags, their compatibility with each other, and rules for mixing styles within a single outfit. Style coherence means that all items in a look belong to compatible style families, creating a unified aesthetic.

เอกสารนี้กำหนด 8 สไตล์หลัก ความเข้ากันของแต่ละสไตล์ และกฎการมิกซ์สไตล์ในชุดเดียวกัน ความสอดคล้องของสไตล์หมายถึงไอเทมทั้งหมดในลุคต้องอยู่ในกลุ่มสไตล์ที่เข้ากัน

---

## 1. The 8 Core Style Tags / 8 สไตล์หลัก

### 1. Minimal / มินิมอล
- **Aesthetic:** Clean lines, neutral palette, no excess / เส้นสายเรียบ สีนิวทรัล ไม่มีส่วนเกิน
- **Key pieces:** Structured blazer, straight pants, simple dress, white sneakers
- **ชิ้นหลัก:** เบลเซอร์ทรง กางเกงตรง เดรสเรียบ สนีกเกอร์สีขาว
- **Colors:** White, black, gray, beige, navy / สีขาว ดำ เทา เบจ กรมท่า
- **Thai keyword:** มินิมอล, เรียบ, ดูแพง

### 2. Streetwear / สตรีทแวร์
- **Aesthetic:** Urban, bold graphics, oversized silhouettes / เมือง กราฟิกเด่น ทรงโอเวอร์ไซส์
- **Key pieces:** Graphic tees, cargo pants, sneakers, hoodies
- **ชิ้นหลัก:** เสื้อยืดกราฟิก กางเกงคาร์โก้ สนีกเกอร์ ฮู้ดดี้
- **Colors:** Bold colors, black, earth tones / สีโดดเด่น ดำ เอิร์ธโทน
- **Thai keyword:** สตรีท, ฮิปฮอป, เท่

### 3. Elegant / เอเลแกนต์
- **Aesthetic:** Sophisticated, refined, luxurious feel / หรูหรา ประณีต ดูมีคลาส
- **Key pieces:** Silk blouses, tailored dresses, heels, structured bags
- **ชิ้นหลัก:** เสื้อผ้าไหม เดรสตัดเย็บ ส้นสูง กระเป๋าทรง
- **Colors:** Black, deep jewel tones, gold, silver / ดำ สีอัญมณี ทอง เงิน
- **Thai keyword:** เอเลแกนต์, หรู, มีคลาส

### 4. Bohemian / โบฮีเมียน
- **Aesthetic:** Free-spirited, flowy, earthy, layered / อิสระ พลิ้ว เอิร์ธโทน เลเยอร์
- **Key pieces:** Maxi dresses, flowy skirts, kimonos, sandals
- **ชิ้นหลัก:** เดรสแม็กซี่ กระโปรงพลิ้ว กิโมโน รองเท้าแตะสวย
- **Colors:** Earth tones, mustard, terracotta, olive / เอิร์ธโทน มัสตาร์ด ดินเผา โอลีฟ
- **Thai keyword:** โบโฮ, ธรรมชาติ, อิสระ

### 5. Preppy / เพรปปี้
- **Aesthetic:** Polished, collegiate, tailored casual / ดูดี วิทยาลัย แคชวลตัดเย็บ
- **Key pieces:** Oxford shirts, chinos, loafers, cable-knit sweaters
- **ชิ้นหลัก:** เสื้อเชิ้ตอ็อกซ์ฟอร์ด ชิโน โลฟเฟอร์ สเวตเตอร์ถัก
- **Colors:** Navy, white, khaki, pastels, stripes / กรมท่า ขาว กากี พาสเทล ลายทาง
- **Thai keyword:** เพรปปี้, สุภาพ, คลีน

### 6. Romantic / โรแมนติก
- **Aesthetic:** Soft, feminine, delicate details / อ่อนหวาน ผู้หญิง ดีเทลละเอียด
- **Key pieces:** Lace blouses, floral dresses, midi skirts, ballet flats
- **ชิ้นหลัก:** เสื้อลูกไม้ เดรสดอกไม้ กระโปรงมิดิ รองเท้าบัลเลต์
- **Colors:** Blush, lavender, cream, soft pink, floral / ชมพูอ่อน ลาเวนเดอร์ ครีม ชมพู ลายดอก
- **Thai keyword:** หวาน, น่ารัก, ผู้หญิง

### 7. Edgy / เอดจี้
- **Aesthetic:** Bold, rebellious, dark, statement-making / โดดเด่น กบฏ เข้ม สร้างความประทับใจ
- **Key pieces:** Leather jackets, boots, distressed denim, hardware accessories
- **ชิ้นหลัก:** แจ็คเก็ตหนัง บูท ยีนส์ขาด เครื่องประดับโลหะ
- **Colors:** Black, dark red, silver hardware / ดำ แดงเข้ม โลหะเงิน
- **Thai keyword:** เอดจี้, ร็อค, ดาร์ก

### 8. Classic / คลาสสิก
- **Aesthetic:** Timeless, traditional, well-constructed / คลาสสิก ดั้งเดิม ตัดเย็บดี
- **Key pieces:** Trench coats, button-down shirts, straight trousers, pumps
- **ชิ้นหลัก:** เสื้อเทรนช์ เสื้อเชิ้ต กางเกงตรง รองเท้าปั๊ม
- **Colors:** Navy, camel, white, black, burgundy / กรมท่า คาเมล ขาว ดำ เบอร์กันดี
- **Thai keyword:** คลาสสิก, ไม่เอาท์, ทุกยุคทุกสมัย

## 4. Style Mixing Rules / กฎการมิกซ์สไตล์

### Rule 1: Maximum 2 Compatible Styles Per Look
ใช้ได้ไม่เกิน 2 สไตล์ที่เข้ากันต่อลุค มากกว่านั้นจะดูวุ่นวาย

### Rule 2: Anchor Piece Sets Primary Style
ชิ้นหลัก (เช่น เดรส, เบลเซอร์, กางเกง) กำหนดสไตล์หลัก ชิ้นเสริมเพิ่มสไตล์รอง

**Example:** Minimal blazer (anchor) + Streetwear sneakers (accent) = Minimal with street edge
**ตัวอย่าง:** เบลเซอร์มินิมอล (ชิ้นหลัก) + สนีกเกอร์สตรีท (ชิ้นเสริม) = มินิมอลมีกลิ่นสตรีท

### Rule 3: 70-30 Ratio
70% of items should be the primary style, 30% can be the secondary compatible style.
ไอเทม 70% ควรเป็นสไตล์หลัก 30% เป็นสไตล์รอง

### Rule 4: Accessories Bridge Styles
Accessories (bags, jewelry, shoes) are the safest way to add a secondary style touch.
เครื่องประดับ (กระเป๋า เครื่องประดับ รองเท้า) เป็นวิธีที่ปลอดภัยที่สุดในการเพิ่มสไตล์รอง
