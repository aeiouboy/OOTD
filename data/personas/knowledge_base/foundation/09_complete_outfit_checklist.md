# Complete Outfit Checklist / เช็คลิสต์ชุดครบเซ็ต

## Overview / ภาพรวม

This document defines what constitutes a "complete outfit" — the minimum and ideal number of items per look, role coverage requirements, and common mistakes. A fashion recommendation is only useful if it results in a complete, wearable outfit.

เอกสารนี้อธิบายว่า "ชุดครบเซ็ต" ต้องมีอะไรบ้าง จำนวนชิ้นขั้นต่ำและในอุดมคติ ข้อกำหนดบทบาทของแต่ละชิ้น และข้อผิดพลาดที่พบบ่อย คำแนะนำแฟชั่นจะมีประโยชน์ก็ต่อเมื่อได้ชุดที่สวมใส่ได้จริง

---

## 1. Minimum Items Rule / กฎจำนวนชิ้นขั้นต่ำ

### Absolute Minimum: 3 Items / ขั้นต่ำสุด: 3 ชิ้น

Every recommended look must have **at least 3 items** to be a wearable outfit.

ทุกลุคที่แนะนำต้องมี **อย่างน้อย 3 ชิ้น** จึงจะเป็นชุดที่ใส่ได้จริง

#### Option A: Separates Formula / สูตรแยกชิ้น
| Role | What | Thai |
|------|------|------|
| Top | Shirt, blouse, tee | เสื้อเชิ้ต เสื้อ เสื้อยืด |
| Bottom | Pants, skirt, shorts | กางเกง กระโปรง กางเกงขาสั้น |
| Shoes | Appropriate footwear | รองเท้าที่เหมาะสม |

#### Option B: Dress Formula / สูตรเดรส
| Role | What | Thai |
|------|------|------|
| Dress | Any one-piece | เดรส จั๊มสูท |
| Shoes | Appropriate footwear | รองเท้าที่เหมาะสม |
| Accessory/Layer | Bag, jacket, or jewelry | กระเป๋า แจ็คเก็ต หรือเครื่องประดับ |

## 2. Ideal Items by Occasion / จำนวนชิ้นในอุดมคติตามโอกาส

| Occasion / โอกาส | Min | Ideal | Components | ส่วนประกอบ |

## 3. Role Coverage System / ระบบบทบาทของไอเทม

Each item in a look plays a specific role. A complete outfit needs proper role distribution.

แต่ละชิ้นในลุคมีบทบาทเฉพาะ ชุดครบเซ็ตต้องมีการกระจายบทบาทที่ดี

### Role Definitions / คำจำกัดความบทบาท

| Role | Description | Quantity | Thai |
|------|-------------|----------|------|
| **Anchor** ชิ้นหลัก | The hero piece that sets the look's direction | 1 | ชิ้นที่กำหนดทิศทางของลุค |
| **Supporting** ชิ้นเสริม | Items that complement the anchor | 1-2 | ชิ้นที่เสริมชิ้นหลัก |
| **Accent** ชิ้นเน้น | Optional items that add personality | 0-1 | ชิ้นที่เพิ่มบุคลิก (ไม่จำเป็นต้องมี) |

### Examples by Occasion / ตัวอย่างตามโอกาส

**Work Look / ลุคทำงาน:**
- Anchor: Tailored blazer เบลเซอร์ (กำหนดว่าเป็นลุคทำงาน)
- Supporting: Dress shirt + Slacks เสื้อเชิ้ต + กางเกงสแล็ค
- Accent: Leather belt เข็มขัดหนัง

**Date Look / ลุคเดท:**
- Anchor: Midi dress เดรสมิดิ (ชิ้นหลักของลุค)
- Supporting: Heeled sandals รองเท้าส้นสูง
- Accent: Clutch bag คลัทช์

**Cafe Look / ลุคคาเฟ่:**
- Anchor: Flowy blouse เสื้อพลิ้ว (ชิ้นน่าสนใจที่สุด)
- Supporting: High-waist jeans ยีนส์เอวสูง + Clean sneakers สนีกเกอร์สะอาด

## 4. Missing Piece Detection / การตรวจจับชิ้นที่ขาด

Common gaps in outfit recommendations and Thai-language prompts for detecting them:

ช่องว่างที่พบบ่อยในการแนะนำชุด พร้อมคำแนะนำภาษาไทย:

### Critical Missing Pieces / ชิ้นที่ขาดแล้วร้ายแรง

| Missing | Impact | Thai Prompt |
|---------|--------|-------------|
| No shoes / ไม่มีรองเท้า | Outfit is incomplete, can't go out | "ชุดนี้ยังขาดรองเท้า เลือกรองเท้าที่เข้ากันด้วยนะ" |
| No bottom / ไม่มีกางเกง (when no dress) | Can't wear just a top | "ต้องมีกางเกงหรือกระโปรงด้วยนะ ไม่งั้นไม่ครบชุด" |
| No top / ไม่มีเสื้อ (when no dress) | Can't wear just pants | "ขาดเสื้อตัวบนอยู่ เลือกเสื้อที่เข้ากับกางเกงด้วย" |

### Important Missing Pieces / ชิ้นที่ขาดแล้วส่งผลกระทบ

| Missing | When It Matters | Thai Prompt |
|---------|----------------|-------------|
| No bag / ไม่มีกระเป๋า | Work, dinner, wedding | "ลุคนี้ควรมีกระเป๋าด้วยนะ จะดูครบเซ็ตกว่า" |
| No layer / ไม่มีเสื้อคลุม | Thai AC offices, evening | "แอร์ออฟฟิศเย็นมาก ควรมีเสื้อคลุมเสมอนะ" |
| No jewelry / ไม่มีเครื่องประดับ | Wedding, dinner, date | "เพิ่มเครื่องประดับชิ้นเดียวจะทำให้ลุคสมบูรณ์ขึ้น" |

### Thai Office AC Warning / คำเตือนแอร์ออฟฟิศไทย 🥶
Thai offices set AC to 22-24°C which is very cold. ALWAYS include a layer option for work outfits.

ออฟฟิศไทยเปิดแอร์ 22-24°C ซึ่งเย็นมาก ต้องแนะนำเสื้อคลุมเสมอสำหรับชุดทำงาน

## 5. Color Harmony Rules / กฎความกลมกลืนของสี

### The 60-30-10 Rule / กฎ 60-30-10
| Portion | Role | Example |
|---------|------|---------|
| 60% | Dominant color (base) สีหลัก | Pants + shoes in navy กางเกง+รองเท้าสีกรมท่า |
| 30% | Secondary color สีรอง | White blouse เสื้อเชิ้ตสีขาว |
| 10% | Accent color สีเน้น | Gold jewelry เครื่องประดับสีทอง |

### Maximum Colors Rule / กฎจำนวนสีสูงสุด
- **Maximum 3 main colors** per outfit / ไม่เกิน 3 สีหลักต่อชุด
- Neutrals (black, white, gray, beige, navy) don't count toward the limit
- สีนิวทรัล (ดำ ขาว เทา เบจ กรมท่า) ไม่นับรวมในลิมิต

### Safe Color Strategies / กลยุทธ์สีปลอดภัย
| Strategy | Description | Thai |
|----------|-------------|------|
| Monochrome | One color, different shades | สีเดียว ต่างเฉด เช่น เบจอ่อน+เบจเข้ม |
| Neutral + Pop | Neutral base + one bright color | นิวทรัลเป็นหลัก + สีเด่นหนึ่งสี |
| Complementary | Opposite colors on color wheel | สีตรงข้ามบนวงล้อสี เช่น น้ำเงิน+ส้ม |
| Analogous | Adjacent colors on color wheel | สีข้างเคียง เช่น เขียว+ฟ้า+น้ำเงิน |
| All neutral | Black, white, gray, beige only | สีนิวทรัลล้วน ปลอดภัยที่สุด |

## 6. Quick Completeness Check / เช็คด่วนความครบถ้วน

Before recommending any look, verify: / ก่อนแนะนำลุค ตรวจสอบ:

- [ ] Has at least 3 items? / มีอย่างน้อย 3 ชิ้น?
- [ ] Has shoes? / มีรองเท้า?
- [ ] Top + Bottom covered (or dress)? / มีเสื้อ+กางเกง (หรือเดรส)?
- [ ] All items within ±2 formality? / ทุกชิ้นอยู่ในช่วง ±2 คะแนน?
- [ ] Maximum 3 main colors? / ไม่เกิน 3 สีหลัก?
- [ ] Styles are compatible? / สไตล์เข้ากัน?
- [ ] Layer included for AC offices? / มีเสื้อคลุมสำหรับแอร์ออฟฟิศ?
- [ ] Bag included for formal occasions? / มีกระเป๋าสำหรับโอกาสทางการ?
