# Formality Scoring Guide / คู่มือระดับความเป็นทางการ

## Overview / ภาพรวม

This document defines the 1-10 formality scoring system used to match clothing items within a cohesive outfit. Every garment has a formality score, and items in the same look must stay within ±2 points of each other to avoid visual mismatch.

เอกสารนี้อธิบายระบบคะแนนความเป็นทางการ 1-10 ที่ใช้จับคู่เสื้อผ้าในชุดเดียวกัน ทุกชิ้นมีคะแนนความเป็นทางการ และไอเทมในลุคเดียวกันต้องอยู่ในช่วง ±2 คะแนนเพื่อไม่ให้ดูขัดกัน

---

## 1. The 1-10 Formality Scale / สเกลความเป็นทางการ 1-10

| Score | Level | Examples (EN) | ตัวอย่าง (TH) |
|-------|-------|--------------|---------------|
| 1 | Ultra-Casual / สบายสุดๆ | Loungewear, sweatpants, flip-flops | ชุดอยู่บ้าน, กางเกงวอร์ม, รองเท้าแตะหนีบ |
| 2 | Very Casual / สบายมาก | Athletic wear, tank tops, running shorts | ชุดกีฬา, เสื้อกล้าม, กางเกงขาสั้นวิ่ง |
| 3 | Casual / แคชวล | Basic tees, jeans, sneakers | เสื้อยืด, ยีนส์, รองเท้าผ้าใบ |
| 4 | Elevated Casual / แคชวลยกระดับ | Polo shirts, chinos, clean sneakers | เสื้อโปโล, กางเกงชิโน, สนีกเกอร์สะอาด |
| 5 | Smart Casual / สมาร์ตแคชวล | Button-down shirts, nice jeans, loafers | เสื้อเชิ้ตปกเปิด, ยีนส์ทรงดี, โลฟเฟอร์ |
| 6 | Business Casual / บิสิเนสแคชวล | Dress shirts, slacks, leather shoes | เสื้อเชิ้ตทำงาน, กางเกงสแล็ค, รองเท้าหนัง |
| 7 | Semi-Formal / กึ่งทางการ | Blazers, tailored pants, heels | เบลเซอร์, กางเกงตัดเย็บ, รองเท้าส้นสูง |
| 8 | Business Formal / ทางการธุรกิจ | Full suits, dress shoes, silk blouses | ชุดสูท, รองเท้าทางการ, เสื้อผ้าไหม |
| 9 | Formal / ทางการ | Evening gowns, tuxedos, formal accessories | ชุดราตรี, ทักซิโด้, เครื่องประดับทางการ |
| 10 | Black Tie / แบล็คไท | Ball gowns, white tie, haute couture | ชุดราตรียาว, ไวท์ไท, โอตกูตูร์ |

## 2. The ±2 Matching Rule / กฎจับคู่ ±2

### Rule / กฎ
All items in a single look must be within **±2 formality points** of each other. This ensures visual coherence—mixing a formal blazer (7) with casual sneakers (3) creates a 4-point gap that looks jarring.

ทุกไอเทมในลุคเดียวกันต้องอยู่ในช่วง **±2 คะแนน** จากกัน เพื่อให้ดูกลมกลืน เช่น ใส่เบลเซอร์ทางการ (7) กับสนีกเกอร์แคชวล (3) ห่างกัน 4 คะแนน จะดูขัดตามาก

### Good Examples / ตัวอย่างที่ดี ✅

| Item 1 | Score | Item 2 | Score | Gap | Result |
|--------|-------|--------|-------|-----|--------|
| Blazer เบลเซอร์ | 7 | Tailored pants กางเกงตัดเย็บ | 7 | 0 | ✅ Perfect |
| Dress shirt เสื้อเชิ้ต | 6 | Leather loafers โลฟเฟอร์หนัง | 5 | 1 | ✅ Great |
| Silk blouse เสื้อผ้าไหม | 8 | Heeled sandals รองเท้าส้นสูง | 7 | 1 | ✅ Great |
| Nice tee เสื้อยืดดีๆ | 4 | Clean sneakers สนีกเกอร์สะอาด | 3 | 1 | ✅ Good |
| Polo shirt โปโล | 4 | Dark jeans ยีนส์สีเข้ม | 4 | 0 | ✅ Perfect |

### Bad Examples / ตัวอย่างที่ไม่ดี ❌

| Item 1 | Score | Item 2 | Score | Gap | Problem |
|--------|-------|--------|-------|-----|---------|
| Blazer เบลเซอร์ | 7 | Flip-flops รองเท้าแตะ | 1 | 6 | ❌ Extreme mismatch |
| Evening gown ชุดราตรี | 9 | Sneakers รองเท้าผ้าใบ | 3 | 6 | ❌ Looks wrong |
| Suit jacket สูท | 8 | Gym shorts กางเกงกีฬา | 2 | 6 | ❌ Completely off |
| Silk dress เดรสผ้าไหม | 8 | Basic tee เสื้อยืดธรรมดา | 3 | 5 | ❌ Too far apart |
| Formal heels ส้นสูงทางการ | 8 | Joggers จ็อกเกอร์ | 2 | 6 | ❌ Mismatch |

## 3. Formality by Occasion / ความเป็นทางการตามโอกาส

Each occasion has a target formality range. All items in the look should fall within this range.

แต่ละโอกาสมีช่วงความเป็นทางการที่เหมาะสม ทุกไอเทมในลุคควรอยู่ในช่วงนี้

| Occasion / โอกาส | Range | Target | Description |
|-------------------|-------|--------|-------------|
| Work / ทำงาน | 6-9 | 7 | Professional, polished / มืออาชีพ เรียบร้อย |
| Wedding / งานแต่ง | 7-10 | 8 | Elegant, formal / สง่างาม ทางการ |
| Party / ปาร์ตี้ | 5-9 | 7 | Fun but polished / สนุกแต่ดูดี |
| Date / เดท | 4-7 | 6 | Attractive, put-together / ดูดี มั่นใจ |
| Cafe / คาเฟ่ | 2-5 | 4 | Trendy, relaxed / เก๋ สบาย |
| Chill / ชิลล์ | 1-4 | 3 | Comfortable, effortless / สบาย ไม่ต้องคิดมาก |
| Sport / ออกกำลังกาย | 1-2 | 1 | Functional, performance / ใช้งานได้จริง |
| Travel / ท่องเที่ยว | 2-5 | 4 | Versatile, comfortable / ใช้ได้หลายสถานการณ์ |
| Dinner / ดินเนอร์ | 5-8 | 7 | Sophisticated, classy / หรูหรา มีคลาส |

## 4. How to Adjust Formality / วิธีปรับระดับความเป็นทางการ

### Dressing UP / แต่งตัวให้ดูทางการขึ้น ⬆️

| Action | Formality Boost | Example |
|--------|----------------|---------|
| Add a blazer / เพิ่มเบลเซอร์ | +2 | T-shirt(3) + blazer → looks 5 |
| Swap sneakers → loafers / เปลี่ยนผ้าใบเป็นโลฟเฟอร์ | +2 | Casual(3) → Smart casual(5) |
| Tuck in shirt / สอดเสื้อ | +1 | Looks more polished |
| Add heels / เพิ่มส้นสูง | +2 | Casual dress(4) → Date-ready(6) |
| Add structured bag / เพิ่มกระเป๋าทรง | +1 | Completes professional look |
| Iron clothes / รีดผ้า | +1 | Crisp = more formal |

### Dressing DOWN / แต่งตัวให้ดูแคชวลลง ⬇️

| Action | Formality Drop | Example |
|--------|---------------|---------|
| Remove blazer / ถอดเบลเซอร์ | -2 | Business(7) → Smart casual(5) |
| Swap heels → sneakers / เปลี่ยนส้นสูงเป็นผ้าใบ | -2 | Formal(7) → Casual(5) |
| Roll up sleeves / พับแขนเสื้อ | -1 | Looks more relaxed |
| Untuck shirt / ปล่อยชายเสื้อ | -1 | More casual vibe |
| Add denim / เพิ่มเดนิม | -1 | Softens formal pieces |
| Swap to crossbody bag / เปลี่ยนเป็นกระเป๋าสะพาย | -1 | More relaxed feel |

## 5. Thai-Specific Formality Tips / เคล็ดลับสำหรับคนไทย

### Office AC Rule / กฎแอร์ออฟฟิศ
Thai offices are very cold (22-24°C). Always include a layer option (blazer, cardigan, or jacket) for work outfits. This also boosts formality by +1 to +2.

ออฟฟิศไทยแอร์เย็นมาก (22-24°C) ต้องมีเสื้อคลุม (เบลเซอร์, คาร์ดิแกน, แจ็คเก็ต) เสมอสำหรับชุดทำงาน ช่วยเพิ่มความเป็นทางการด้วย +1 ถึง +2

### Thai Wedding Warning / ข้อควรระวังงานแต่งไทย
Thai weddings require formality 7-10. Even if you're "just a friend," underdressing is considered disrespectful. Invest in the outfit for this occasion.

งานแต่งไทยต้องการความเป็นทางการ 7-10 แม้จะไป "แค่เพื่อน" การแต่งตัวไม่เป็นทางการถือว่าไม่ให้เกียรติ ลงทุนกับชุดสำหรับโอกาสนี้

### Bangkok vs Provinces / กรุงเทพ vs ต่างจังหวัด
Bangkok allows slightly more creative formality combinations. In provinces, stick closer to traditional formality expectations.

กรุงเทพยืดหยุ่นเรื่องการมิกซ์ความเป็นทางการได้มากกว่า ต่างจังหวัดควรยึดแนวทางดั้งเดิม
