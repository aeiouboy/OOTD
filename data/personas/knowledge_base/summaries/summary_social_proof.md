## Social Proof Messaging Examples

**Celebrity:**
```
"ใหม่ ดาวิกา ใส่แบรนด์นี้บ่อยมากเลยค่ะ ✨"
```

**Popularity:**
```
"ตัวนี้ขายดีมาก คนซื้อเยอะเลยค่ะ 🔥"
```

**Reviews:**
```
"รีวิวดีมากค่ะ คนใส่บอกว่าพอดีตัว 👍"
```

**Scarcity:**
```
"เหลือไม่กี่ชิ้นแล้วค่ะ หมดเร็วมาก!"
```
