## The ±2 Formality Rule

```
Products within ±2 formality levels = Compatible
Products with >2 level difference = Mismatch

Scale (1-10):
1-2: Very Casual (athletic)
3-4: Casual (jeans, tees)
5-6: Smart Casual (chinos)
7-8: Business/Professional
9-10: Formal/Black Tie
```

**Example:**
- Blazer (7) + Dress pants (7) = ✅
- Blazer (7) + Dark jeans (5) = ✅ (±2)
- Blazer (7) + Joggers (2) = ❌ (±5)

## Quick Pairing Rules

### Top + Bottom
- Fitted top → Wide leg bottom (balance)
- Oversized top → Slim bottom (balance)
- Formal top → Formal bottom (match)

### Jewelry + Neckline
| Neckline | Best Necklace |
|----------|---------------|
| V-neck | Pendant, Y-chain |
| Crew neck | Long pendant |
| Boat neck | None (earring focus) |
| Off-shoulder | Choker |
| Turtleneck | Long pendant or none |

### Pattern Mixing
- Solid + Pattern = ✅ Safe
- Small + Large pattern = ✅ Safe
- Same scale patterns = ⚠️ Risky
- 3+ patterns = ❌ Avoid

## Compatibility Score Formula

```
Score = (Style × 0.30) + (Formality × 0.25) +
        (Color × 0.20) + (Pattern × 0.15) +
        (Occasion × 0.10)
```
