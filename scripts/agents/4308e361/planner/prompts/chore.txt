/chore 4308e361 Enhance image generation API to support reference images for fitting model face-matching.

  **Problem:**
  The fitting-model-service.ts passes user photo base64 in text prompt, but the generate-image API doesn't actually send it as an image reference to the model. This prevents accurate face-matching.

  **Requirements:**

  1. **Update ImageGenerationRequest type** (apps/web/lib/types/image-types.ts):
     - Add optional `referenceImage?: string` field for base64 image input
     - Add optional `generationType?: 'outfit' | 'fitting-model'` field

  2. **Update OpenRouterImageClient** (apps/web/lib/services/image-generation-service.ts):
     - Add method `generateFittingModelImage(prompt: string, referenceImageBase64: string)`
     - Use OpenRouter's vision/multimodal capability to pass reference image
     - The model should receive both the text prompt AND the user's face image

  3. **Update generate-image API route** (apps/web/app/api/generate-image/route.ts):
     - Accept `referenceImage` in request body
     - Route to appropriate generation method based on `generationType`
     - Increase timeout for fitting model generation (may take longer)

  4. **Update fitting-model-service.ts**:
     - Pass user photo as `referenceImage` field instead of embedding in text prompt
     - Set `generationType: 'fitting-model'`

  **Reference:**
  - OpenRouter multimodal docs for passing images
  - data/personas/prompt_gen/fitting_model.md for prompt template
