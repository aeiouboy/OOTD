## 🔴 Critical Issues

### Issue 1: URL Query Parameter Not Working
**Priority**: P0 - Critical

**Description**
The `?outfit=` URL query parameter doesn't trigger outfit selection on page load. Deep linking to specific outfits is broken.

**Current Behavior**
- URL: `http://localhost:3000/?outfit=outfit-1759725680949-jtkm7b6q0`
- Page loads with default state (no outfit selected)
- Query parameter is ignored

**Expected Behavior**
- Parse `outfit` query parameter on component mount
- Auto-select and display outfit in right panel
- Update URL when outfit is selected (already working)
- Support browser back/forward navigation

**Location**
- File: `frontend/app/page.tsx`
- Component: `HomePage`
- Lines: 21-99 (needs `useSearchParams()` or URL parsing in `useEffect`)

**Technical Requirements**
1. Use Next.js `useSearchParams()` hook to read URL parameters
2. Add effect to select outfit by ID from URL on mount
3. Handle case when outfit ID doesn't exist (show error or fallback)
4. Sync URL with outfit selection state

**Acceptance Criteria**
- [ ] Opening URL with `?outfit={id}` displays that outfit
- [ ] Invalid outfit IDs show appropriate error/fallback
- [ ] Browser back/forward buttons work correctly
- [ ] Sharing URL with outfit parameter works across devices

**Impact**: High - Breaks sharing, deep linking, and user bookmarking

## Technical Notes

### URL Parameter Handling Example
```tsx
// In frontend/app/page.tsx
import { useSearchParams } from 'next/navigation'

export default function HomePage() {
  const searchParams = useSearchParams()

  useEffect(() => {
    const outfitId = searchParams.get('outfit')
    if (outfitId && allOutfits.length > 0) {
      const outfit = allOutfits.find(o => o.id === outfitId)
      if (outfit) {
        selectOutfit(outfit)
      }
    }
  }, [searchParams, allOutfits])

  // ... rest of component
}
```
